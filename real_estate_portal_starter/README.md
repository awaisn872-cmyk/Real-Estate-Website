
# Real Estate Portal Starter (Full Stack)

Stack:
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js + Express
- Database: MongoDB (Mongoose)

## Setup

1. Install Node.js
2. Open project folder in terminal
3. Run:
   npm install
   node server.js

Server runs on:
http://localhost:3000

## Features (Starter)
- Add property
- View property listings
- Image upload
- MongoDB storage
- Simple REST API

You can extend:
- login/signup
- dashboards
- AI search
- Google Maps
- favorites
- scheduling visits
